This project focuses on cleaning and analyzing a real-world laptop pricing dataset containing ~1,300 rows with specifications like RAM, storage, brand, and price. Using Python, NumPy, and Pandas, I handled missing values, removed inconsistencies, standardized data types, and sorted/filtered records to prepare a clean, analysis-ready dataset. I performed feature engineering to extract meaningful attributes from raw specification columns, improving the dataset's usability for further analysis. Exploratory Data Analysis (EDA) was carried out using Matplotlib and Seaborn to visualize trends in pricing across brands, RAM configurations, and other specs. The project also incorporates data profiling to summarize dataset structure, distributions, and quality issues. Overall, it demonstrates an end-to-end data cleaning and preprocessing pipeline commonly used before building ML models.
